# mammography-ai
The project investigates deep learning performance for breast cancer detection on digital mammography across
distinct cancer subtypes.
It evaluates pretrained mammography classification workflows and examines methodological considerations such as
patient-level data splitting and subgroup sensitivity.
Open-access mammography resources, including the Chinese Mammography Database (CMMD), are used to structure 
reproducible experiments and literature synthesis.
All notes, literature screening logs, and code/documentation drafts are organized for transparent research
tracking.
